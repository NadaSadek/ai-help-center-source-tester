# Export permissions

Export permissions control which users can download dashboard and report data from ExampleOps.

Workspace owners and admins can grant export access from the member settings page. Some roles can view dashboards but cannot export data.

If a user cannot see the export button, confirm their workspace role and export permission settings.

Export permissions are separate from billing permissions. A user may be allowed to manage invoices but not export customer or report data. A user may also be able to use the workspace but not download data.

If export permissions look correct but the export is still unavailable, check plan limits and browser troubleshooting information.
