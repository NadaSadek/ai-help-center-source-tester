# Export dashboard data

ExampleOps allows users with export permissions to export dashboard data as a CSV file.

Exports include the data visible from the selected dashboard, based on the current workspace and report configuration. Large exports may take longer to generate.

Dashboard exports are different from invoices. Billing invoices are downloaded from billing settings, while dashboard data exports are created from reporting pages.

Some plans include export limits. If the export option is unavailable, check your plan limits and export permissions.

If you need to export only the rows matching active filters, use filtered exports instead of exporting the full dashboard data.
