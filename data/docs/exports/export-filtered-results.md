# Export filtered results

Filtered exports allow users to download only the rows that match the filters currently applied to a dashboard or report.

Before exporting, apply the filters you want to use. ExampleOps will generate a CSV file based on the filtered result set rather than the full dashboard.

Filtered exports are useful when you need a subset of customers, workflows, tickets or activity records.

If the export includes more rows than expected, check whether the filters were applied before starting the export.

Filtered exports require export permissions and may be affected by plan limits. If you cannot export filtered results, review export permissions and plan limits.
