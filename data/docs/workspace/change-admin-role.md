# Change workspace admin role

Workspace owners can promote members to admin roles from the member management page.

Admins can manage workspace membership, invitations and some workspace settings, but billing permissions may still be separate depending on the assigned role.

If an admin left the company, a workspace owner should assign a replacement admin to maintain access and workspace management continuity.

If nobody can manage the workspace because the previous admin or owner is unavailable, contact ExampleOps support for recovery steps.

Changing a workspace admin role does not automatically resolve billing sync or payment-related access issues. If access changed after a billing event, review failed payment and entitlement sync information as well.
