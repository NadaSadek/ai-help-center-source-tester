# Troubleshoot workspace access

If a user cannot access an ExampleOps workspace, first confirm that they were invited to the correct workspace and accepted the invitation with the expected email address.

Workspace access issues can happen when a user was removed from the workspace, accepted an invite with the wrong email address, signed in through the wrong authentication method or does not have the required role.

If only some users are affected, ask a workspace owner or admin to review the member list and confirm the affected users still appear as active members.

If the workspace recently changed plan status or had a payment issue, access to some features may depend on entitlement sync. In those cases, review entitlement sync information in addition to billing status.

Workspace access is different from billing permissions. A user may be able to use the workspace but still be unable to manage billing, invoices or payment methods.
