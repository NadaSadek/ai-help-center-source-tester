# Entitlement sync after billing changes

ExampleOps uses entitlement sync to apply billing and plan changes to workspace access and feature availability.

When a payment succeeds, fails or a subscription changes, billing status and workspace entitlements may take a short time to sync. During this period, a workspace may show a paid invoice while some users still cannot access paid features or expected limits.

If a workspace remains out of sync after a billing update, a workspace owner should confirm the latest billing status, wait for the sync window to complete and then contact support if access is still incorrect.

Entitlement sync issues are different from invitation or role problems. If only one user cannot access the workspace, review workspace membership and role configuration first.

If the whole workspace is affected after a payment or subscription change, entitlement sync is a more likely cause than individual user access settings.
